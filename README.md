# Channel Softech Website Builder

An internal tool for Channel Softech (P) Ltd. that generates complete, independent PHP/MySQL websites from a library of category templates. Every generated site has its own code, database, and admin panel, and it can be exported as a ZIP + SQL package and deployed to any cPanel host.

- Architecture: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- Install on cPanel: [docs/INSTALL.md](docs/INSTALL.md)
- Template guide: [docs/TEMPLATE_GUIDE.md](docs/TEMPLATE_GUIDE.md)
- Progress: [docs/PROGRESS.md](docs/PROGRESS.md)

**Stack:** PHP 8.1+, MySQL 5.7+ / MariaDB 10.3+, Bootstrap 5, jQuery, AJAX. All front-end libraries are bundled locally.

*Status: Phase 1 (core platform) complete. Phase 2 (template engine) is next.*
